            Syncing with

            Keeps your phone and Mac matched through a private GitHub project. Set it up once on each device.

            How to make an access key
            1. On github.com, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
            2. Name it “Z4 Log sync”, and choose the longest expiration offered.
            3. Repository access: Only select repositories → z4-log-data.
            4. Permissions → Repository permissions → Contents: Read and write.
            5. Generate, copy the key, and paste it above. Use the same key on your other device.
